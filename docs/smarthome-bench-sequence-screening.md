## 평가 세트 구성

- 반려동물 중심: **0009, 0019, 0041, 0065**를 우선 사용. 0017·0030·0040은 미세 행동이나 약한 시퀀스에 대한 보조 사례.
- 시간순 처리 검증: **0008, 0021, 0029**를 별도로 사용. 서비스의 반려동물 행동 정확도 점수에 섞지 않는다.
- 0022처럼 영상 안에 다른 장면이 붙은 경우, 원본 전체를 그대로 처리하면 이벤트가 서로 다른 사건을 하나의 녹화로 연결할 수 있다. 클립 경계를 먼저 확인한다.
- 0062처럼 데이터셋 설명과 눈으로 확인한 영상 구간이 어긋나는 경우가 있다. 설명을 정답으로 자동 변환하지 않고, 실제로 확인한 프레임에서만 행동을 채택한다.
- 관찰 시점: [sequence-pilot-observations.csv](sequence-pilot-observations.csv).
- 임시 구간: [sequence-pilot-intervals.csv](sequence-pilot-intervals.csv). 시작·종료 초는 탐색한 화면을 바탕으로 좁힌 **대략의 경계**다. 평가 정답으로 쓰기 전 전체 영상을 연속 재생하며 수정한다.

## 노트북에서 확인할 질문

| ID | 시퀀스 질문 | 확인할 순서 |
|---|---|---|
| 0009 | 다람쥐와 고양이가 등장하고 움직인 순서를 알려줘 | 다람쥐가 먹이대에 있음 → 고양이가 왼쪽에 보임 → 다람쥐가 오른쪽으로 이동 |
| 0019 | 강아지가 현관 앞에서 어떤 순서로 움직였어? | 사람이 안고 있음 → 바닥에 서 있음 → 카메라 가까이 다가옴 |
| 0041 | 고양이가 도어벨 앞에서 한 행동의 순서를 알려줘 | 카메라 가까이에서 살핌 → 몸을 돌림 → 화면에서 사라짐 |
| 0065 | 강아지가 거실과 소파 사이에서 움직인 순서를 알려줘 | 바닥에서 달림 → 소파 위에 있음 → 내려옴 → 화면 아래쪽에 다시 보임 |

위 문장들은 **관찰한 시점의 상대적 순서**만 답으로 삼는다. 각 행동의 정확한 초 단위 경계와 `A 때문에 B` 같은 인과관계는 이 자료로 평가하지 않는다. 서비스에 영상을 실제로 넣은 뒤 같은 질문을 실행하고, 답변 순서와 근거 장면을 함께 확인해야 한다.

### 추가 검증 질문

| 목적 | 질문 예시 | 기대하는 검증 |
|---|---|---|
| 같은 의미의 표현 | `강아지 행동 흐름을 보여줘` / `강아지 행동을 시간순으로 알려줘` | 같은 영상·날짜에서 두 답의 순서가 같아야 함 |
| 첫 행동 | `강아지가 가장 먼저 한 행동은 뭐야?` | 가장 이른 이벤트를 근거 영상과 대조 |
| 시간 범위 | `오전 중 강아지 행동 순서를 알려줘` | API의 `time_range`를 오전으로 지정하고 범위 밖 이벤트가 없는지 확인 |
| 빈 결과 | `이 날짜에 고양이가 한 행동 순서를 알려줘` | 이벤트 없는 날짜를 선택하면 순서를 지어내지 않아야 함 |
| 대상 구분 | `다람쥐와 고양이가 등장한 순서를 알려줘` (0009) | 다람쥐의 행동을 고양이 행동으로 바꾸지 않는지 확인 |
| 재등장 | `강아지가 소파에 있었다가 다시 나타난 순서를 알려줘` (0065) | 소파에서 내려온 뒤 재등장을 빠뜨리지 않는지 확인 |
| 근거 재생 | `고양이가 도어벨 앞에서 한 행동 순서를 알려줘` (0041) | 각 항목의 재생 위치가 해당 행동 장면인지 확인 |

현재 시퀀스 경로는 **질문에 맞는 일부 행동만 골라 관계를 판단하는 기능이 아니라 전체 이벤트를 시간순으로 보여주는 기능**이다. 따라서 `소파에서 내려온 다음에 어디로 갔어?`, `고양이가 나온 뒤 강아지도 나왔어?`, `가장 마지막 행동은 뭐야?`는 다음 단계의 **실패 탐지 질문**으로 둔다. 이 질문에 목록을 반환하는 것만으로 정답 처리하면 안 된다. 화면 요청은 현재 `top_k=3`이라 0065의 네 번째 행동이 잘릴 수 있다. 해당 영상의 전체 순서를 검증할 때는 API에서 `top_k=10`으로 요청하거나 화면 표시 개수를 조정한다.

## 다음 측정

1. 추천 영상의 실제 행동 시작·종료 시각을 프레임 단위로 확정한다.
2. 각 영상의 참 행동 순서와 서비스 출력의 순서 일치율을 비교한다.
3. 출력된 근거 장면을 눌러 참 구간과 겹치는지 확인한다.
4. 이벤트가 빠진 경우 `추출 실패`, `정렬 실패`, `행동 설명 실패`, `재생 연결 실패` 중 원인을 기록한다.
