# `0142`·`0065` 순서 질문 검수 (2026-11-19)

## 원본 대조

로컬 MP4를 1초 단위와 주요 시점의 고해상도 프레임으로 확인했다. 모델이 기록한 기존 행동 설명을 그대로 순서 정답으로 쓰지 않았다.

- `0142`: 원본은 영상 초반부터 먹고 있고, 약 10.5초에 고개를 든 뒤 19초 무렵 다시 먹는다. 약 25초에 다시 고개를 들고, 약 28초부터 영상 끝까지 다시 먹는다. 기존 DB의 “10.51초에 그릇으로 몸을 기울임 → 12.51초에 다가감” 순서는 원본과 다르다.
- `0065`: 2초에 바닥 이동, 6초에 소파 위, 9초에 소파 아래 바닥 이동, 18초에 거실 바닥 재등장, 22초에 다시 소파 위가 보인다. 화면 전환과 빠른 움직임 때문에 모든 소파 진입·이탈 순간을 프레임별로 확정할 수 없다. 순서 답변에 이 한계를 명시한다.

각 영상의 검수 타임라인은 [0142 데이터](../notebooks/smarthome-bench-evidence/sequence-reviewed-0142.json), [0065 데이터](../notebooks/smarthome-bench-evidence/sequence-reviewed-0065.json)에 있다. 기존 저장 프레임이 없던 0142의 4·20·30초와 0065의 9초 JPEG만 프로젝트의 비공개 GCS `frames/` 경로에 새 객체로 올렸다. 기존 객체는 덮어쓰지 않았다.

## DB 갱신과 브랜치 검증

재인덱싱 도구는 검수 데이터의 영상·기존 이벤트 ID가 현재 DB와 일치하는지 검사하고, 적용 전 GCS 근거 프레임의 존재를 확인한다. 기존 사건은 각각 `/private/tmp/smartbench_0142-sequence-backup-2026-11-19.json`, `/private/tmp/smartbench_0065-sequence-backup-2026-11-19.json`에 백업했다.

| 영상 | 교체한 기존 사건 | 새 사건 | 브랜치 실제 API 순서 결과 |
| --- | --- | --- | --- |
| `0142` | 103~107, 129~130 | 159~163 | 먹기 → 고개 들기 → 먹기 → 고개 들기 → 먹기, 5카드 |
| `0065` | 109~114 | 164~168 | 바닥 이동 → 소파 위 → 내려와 이동 → 재등장 → 소파 위, 5카드 및 불확실성 안내 |

`0065`의 “소파에서 내려온 다음”은 재등장 카드 ID 167을 반환한다. 두 영상의 횟수 질문은 기존 요청대로 정확한 수치를 단정하지 않고 검토된 시간대의 반복 행동을 설명한다. `0142`의 “고개를 든 채 주변을 바라봄”은 위치 단어 `주변` 때문에 행동 필터에서 제외되던 문제를 고쳤다.

전체 단위 테스트 286개와 `git diff --check`가 통과했다. 스테이징 API와 웹 재생은 이 브랜치 코드 배포 후 별도로 확인한다.
