# 추천 질문 문장 품질 평가 (2026-09-27)

실제 DB와 gpt-4o-mini를 사용해 각 영상의 `suggest_query_items(video_id=..., limit=3)`를 수정 전/후 각 1회 호출했다. 검색·선정·라벨 보충 코드는 변경하지 않았다. LLM 출력은 호출마다 달라질 수 있다. 검증은 문장 규칙과 저장된 이벤트 메타데이터 기준이며 영상 픽셀을 다시 판독한 평가는 아니다.

## 원인과 수정

- 기존 프롬프트의 좋은 예시에 관심·오래·반복이 포함되어 있었고 반복 횟수 검증이 없었다.
- 기존 fallback은 대상만 있으면 관심과 오래 머무름 질문을 추가했고, 근거 없는 기본 질문으로 개수를 채웠다.
- 기존 category는 같은 급식기 이벤트의 '머문'과 '관심' 질문을 서로 다른 종류로 분류했다.
- 새 프롬프트는 행동 → 명시된 위치/대상 → 등장 여부 순서로 직접 관찰 사실만 묻는다. 감정/의도를 위치나 행동으로 바꾸되 관찰 사실이 없으면 제외한다.
- 생성 응답은 `event_index`와 `question`을 가진 JSON 배열이다. 공개 함수의 반환형은 기존 `list[str]` 그대로다.
- 지속시간 강조는 모두 제외한다. 반복 표현은 지정 근거 이벤트와 기존 최종 연결 규칙의 이벤트 모두 repeat_count >= 2여야 한다. 감정/의도 표현은 후보 전체를 제거한다.
- 생성 근거 또는 최종 연결 이벤트가 겹치는 생성 후보는 하나만 남긴다. 라벨 보충은 기존대로 처리한다.
- API 실패/키 부재 fallback도 관찰 절에서 완성된 질문을 선택하고 같은 검증을 거친다. 정상 LLM 결과가 검증에서 탈락해도 개수를 억지로 채우지 않는다.

## duration 분포

전체 저장 이벤트 17개: 최소 0초, 중앙값 6초, 최대 178초. 0초 3개, 0초 초과 10초 미만 7개, 10초 이상 7개.
정렬값: 0, 0, 0, 1.5, 3, 3.5, 4.5, 5.5, 6, 8.5, 15, 30, 34.5, 54.06, 54.5, 55.5, 178.
이벤트 구간 길이만으로 동일 행동이 연속적으로 지속됐는지 보장할 수 없어 임의의 최소 초 기준을 도입하지 않았다. 이번에는 duration 값과 관계없이 지속시간 강조 표현을 생성/허용하지 않는다.

## 제거 확인 및 새 질문

실제 수정 전 최종 질문의 “자동 급식기 근처에 오래 머문 구간은 언제야?”, “자동 급식기에 관심을 보인 장면이 있어?”, “장애물 위로 뛰어오르려는 장면이 있어?”가 수정 후 최종 결과에서 사라졌다.
수정 전 생성 후보에는 “반려동물이 물을 마시는 행동이 반복된 장면이 있어?”도 있었다. 수정 후 생성/최종 후보에는 반복 표현이 없었다.
새 최종 생성 질문은 “자동 급식기 근처에 있는 장면이 있어?”, “사료 그릇에 접근한 장면이 있어?”, “물을 마신 장면이 있어?”였다.
기다림·호기심·불안·편안 등은 회귀 테스트에서 제거를 검증했다. 수정 전 실제 최종 결과에 없었던 표현을 실제 호출에서 제거했다고 주장하지 않는다.
공간 진입·이동·사람 등장 문장의 검증 통과는 회귀 테스트로 확인했다. 이번 실제 수정 후 생성 결과에서는 공간 진입 질문이 없었고, 이동과 사람 등장은 기존 라벨 보충에서 나왔다.

## 범위 밖 관찰

- dog_drinking_water의 물 마시기 질문은 기존 연결 규칙에 의해 event #17(duration 0)에 연결된다.
- IMG_8450_2의 주변 돌아다니기 이벤트 #4는 기존 연결 규칙/중복 제한으로 탈락할 수 있다. 다양한 이벤트 보존보다 잘못된 반복/중복을 줄이는 보수적 선택이다.
- dog_escape와 two_dogs는 이번 수정 후 생성 후보가 0개여서 기존 라벨 질문으로 3개를 채웠다. dog_escape의 “침대을” 조사 오류는 기존 query_suggester의 라벨 질문이다.
- dog_drinking_water와 two_dogs의 고양이 질문은 기존 라벨 데이터/보충 로직에서 나왔다. 영상 이름만으로 라벨의 사실 여부를 단정하지 않았다.
- 라벨 보충과 기존 이벤트 연결은 같은 이벤트에 여러 질문을 연결할 수 있다. 생성 후보에 적용한 이벤트당 1개 제한이 최종 라벨 보충까지 보장하는 것은 아니다.
- 일부 repeat_count는 실제 행동 횟수가 아니라 프레임 수다(two_dogs #1: 90). 추출 로직은 수정하지 않았다. 프롬프트는 프레임 감지 횟수만으로 반복 질문을 만들지 않도록 한다. 숫자 검증만으로 이 의미 차이까지 보장할 수는 없다.
- 정규식 검증은 명시적 금지 표현을 차단하며 모든 의역이나 환각을 의미적으로 판별하는 검증기는 아니다.
